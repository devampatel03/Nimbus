## API auth (single-user JWT) [SUPERSEDED by ADR-0012; code removal P2.1b]

- Login: `POST /auth/token {"password": "..."}` -> `{"access_token": "...", "token_type": "bearer"}`. Exempt from `JWTAuthMiddleware` (can't require a token to get one).
- Every other route requires `Authorization: Bearer <token>`. WebSocket also accepts `?token=<token>` as a query param, since browser `WebSocket` clients can't set custom handshake headers.
- `settings.auth_password`/`settings.jwt_secret_key` ship dev-only placeholder defaults (same pattern as `postgres_password`) -- both MUST be overridden via `.env` before any real deployment.

Fixed by moving every such literal into a single module-level constant per role (`_TEST_PASSWORD`, `_WRONG_PASSWORD`) with one `# pragma: allowlist secret` comment at each constant's definition, then referencing the constants everywhere else as plain variables (which the plugin can't flag, since it only matches literal strings) -- cleaner than sprinkling pragma comments at every call site, and immune to the next problem.
- `# pragma: allowlist secret` must be an inline trailing comment on the *exact same physical line* as the flagged literal, not on a following line (e.g. a wrapped closing paren). `ruff format` will happily wrap a >100-char statement across multiple lines and float the trailing comment onto whichever line it lands on syntactically, which can silently separate the pragma from the secret it was meant to cover -- re-run the actual `detect-secrets` hook (not just `ruff format`) after any reformatting near a pragma-annotated line, don't assume the pragma "moved with" the code it was commenting on.
- 2026-09-14 (T0.4, eval harnesses): the real public LoCoMo dataset (`snap-research/locomo`'s `data/locomo10.json`, ~2.7MB) is fetchable directly at `https://raw.githubusercontent.com/snap-research/locomo/main/data/locomo10.json` -- network access to GitHub raw content is available in this environment. Its QA `category` field (1-5) is undocumented in the JSON itself; resolved by fetching the repo's own `task_eval/evaluation.py` and reading how it branches on category number (`[2,3,4]` grouped as "single-hop, temporal, open-domain", `[1]` as multi-hop with sub-answer splitting, `[5]` as adversarial expecting "no information available" -- and category 5's QA entries have no `answer` key at all, confirming that mapping), then cross-checking actual question wording per category (all category-2 questions are "When did X do Y" -> temporal) rather than trusting the paper's category-name ordering assumption alone.
- Running a script with `uv run python path/to/file.py` does NOT get `pyproject.toml`'s `[tool.pytest.ini_options] pythonpath = ["."]` treatment -- that only applies inside `pytest` runs. Any `tests/eval/*.py` file meant to "run unattended" as a standalone script (not via pytest) and that imports `src.*`/`config.*` needs its own `sys.path.insert(0, str(Path(__file__).resolve().parents[N]))` to the repo root before those imports, done at true module top (before the imports it's fixing), not deferred into an `if __name__ == "__main__":` guard -- a module-level `from src...` import runs before `__main__` code ever executes.

## 2026-10-29 - P4.4: canary tripwires (ADR-0023, Proposed)
- New module `src/canary`: per-site canaries (system prompt, memory preamble, tool-output frame) from HMAC(`CANARY_SEED`); random per process without a seed. They reach the model on purpose and are redacted from the stored audit payload.
- One `CanaryGuard` screens the final reply (`canary_blocked`), tool arguments (`deny.canary`, before the policy, also on approved calls), every Telegram send (`TelegramGateway._outbound_chunks` and approval card / keypad text, via `set_outbound_screen`), every `EgressClient.request` (`set_outbound_check`), and logs (`add_log_matchers`). Obfuscations: skeleton folding, 10-char fragments, reversed/ROT13, nested base64/hex/base32/escapes/char codes, and a stream window for split or out-of-order pieces.
- A hit writes `policy_audit` (`event=canary_blocked`, fixed codes only) and sends one fixed-text alert per cooldown. `python -m src.app canary-sweep` is the INV-7 DB sweep (counts only).
- Limits: a model-invented cipher, or pieces under 6 chars, are not detected. It is a tripwire, not a boundary.
